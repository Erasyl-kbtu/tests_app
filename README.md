# Тесты Алтын Каппасовны — Перенос и запуск на другом ноутбуке

## Что нужно на новом ноутбуке
1. Установить **Node.js (версия 22 или 24 LTS)** с официального сайта: https://nodejs.org (при установке нажимать «Далее» до конца).

## Как перенести проект
Скопируйте папку `biology_tests` на флешку (или упакуйте в `.zip` и отправьте себе).

> **Совет для быстрого копирования:** папку `client\node_modules` можно **не копировать** (она большая и нужна только для разработки). Обязательно оставьте:
> - `server\`
> - `client\dist\` (готовый собранный сайт)
> - `data\` (если хотите перенести уже созданные тесты)
> - `package.json` и `Запустить_Тесты.bat`
> - `node_modules\` (если скопируете её, сайт запустится вообще без интернета; если не скопируете — она сама установится при первом запуске).

## Как запустить на новом ноутбуке
1. Откройте скопированную папку `biology_tests`.
2. Дважды нажмите на файл **`Запустить_Тесты.bat`**.
3. Если Windows Firewall (Брандмауэр) спросит разрешение для `Node.js` — нажмите **«Разрешить доступ»** (чтобы телефоны учеников могли подключаться по Wi-Fi).
4. Браузер сам откроет страницу учителя: `http://localhost:3000/teacher`.
